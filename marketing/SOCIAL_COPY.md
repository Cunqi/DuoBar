## Reddit — r/macapps

### Title

I recreated the iPhone Duo three-in-one status bar on my MacBook — DuoBar 0.1 Beta

### Post

I built DuoBar, a small native SwiftUI/AppKit menu-bar utility that combines three live Mac states into one compact glyph:

- outer arc: battery level
- center: Wi-Fi connection and signal
- four lower dots: Bluetooth state
- lightning indicator: charging

The first Beta is open source and available for Apple Silicon Macs on macOS 15+. It is still an early, non-notarized build, so macOS may require explicit approval on first launch. I would especially appreciate feedback on readability and how naturally it fits alongside system menu-bar items.

https://github.com/Mikeli7666/DuoBar

## Reddit — r/macOS

### Title

I adapted the iPhone Duo status concept into a native macOS menu-bar app

### Post

DuoBar maps battery, Wi-Fi, and Bluetooth into a single live menu-bar indicator instead of displaying three unrelated icons. It uses SwiftUI with AppKit menu-bar integration and reads system state through public macOS APIs.

Version 0.1 is an open-source Beta for macOS 15+ on Apple Silicon. It is independently distributed and not yet Developer ID notarized.

Project and download: https://github.com/Mikeli7666/DuoBar

### 正文

做了一个原生 macOS 菜单栏小工具：DuoBar。

它把三个实时状态压进同一个小图标里：

- 外圈弧线：电池电量
- 中间图形：Wi-Fi 连接和信号
