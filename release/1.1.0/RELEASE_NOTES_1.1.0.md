# DuoBar 1.1

DuoBar 1.1 expands the original three-state menu bar indicator with adaptive desktop monitoring, improved battery behavior, broader Mac support, and localization.

## What's New

### Adaptive Ring

On desktop Macs, the outer ring can represent display brightness and automatically surface CPU, memory, or thermal pressure when it matters.

### Battery Ring

Charging now has a dynamic bolt that follows battery progress. Optional Battery Color Coding reflects charging, Low Power Mode, and low battery states.

### Adjustable Icon Size

Adjust DuoBar's menu bar size to better match your setup.

### More Macs

DuoBar now supports macOS 13+ and both Apple Silicon and Intel Macs through a Universal 2 build.

### Localization

Added Simplified Chinese and Traditional Chinese.

### New App Icon

DuoBar has a new app icon.

## Installation

Download DuoBar-1.1.0.dmg and move DuoBar to Applications.

This build uses Hardened Runtime and ad-hoc signing but is not yet notarized. If macOS blocks the first launch, right-click DuoBar and choose Open, or use System Settings → Privacy & Security → Open Anyway.
